# NotreMock (نوترماک)

> **مستندات دوزبانه:** [English](README.md) | **فارسی**

**NotreMock** یک اپلیکیشن سبک، متن‌باز و متمرکز بر حریم خصوصی برای شبیه‌سازی موقعیت مکانی (Mock Location) در اندروید است که با Kotlin و Jetpack Compose ساخته شده است. این برنامه به گونه‌ای طراحی شده که روی **۹۹٪ گوشی‌های اندرویدی (اندروید ۷.۰ به بالا / API 24+)** با ظاهری بسیار تمیز و مینیمال کار کند و در عین حال قابلیت‌های تخصصی **Shizuku** و **Root / LSPosed** را در بخشی کاملاً مجزا در اختیار کاربران حرفه‌ای بگذارد.

---

## قابلیت‌های کلیدی

- **صفحه اصلی تک‌دکمه‌ای و ویجت صفحه اصلی**: روشن/خاموش کردن سریع آخرین شهر و تنظیمات با یک لمس از داخل برنامه، **ویجت استاندارد صفحه اصلی** یا **آیکون Quick Settings** بالای گوشی.
- **تور مرحله‌ای راه‌اندازی و عیب‌یابی زنده**: راهنمای گام‌به‌گام مخصوص برند گوشی شما (**سامسونگ، شیائومی/HyperOS، هواوی/آنر، اوپو/ریلمی/وان‌پلاس، اندروید خام**) برای فعال‌سازی Developer Options، انتخاب اپ Mock Location، و جلوگیری از بسته شدن برنامه در پس‌زمینه (Battery Optimization) همراه با تشخیص دقیق علت مشکل.
- **دیتابیس آفلاین شهرهای دنیا**: شامل حدود **۲٬۶۸۴ پایتخت و مرکز استان/ایالت دنیا** (از جمله هر ۳۱ مرکز استان ایران) با جستجوی فوری به **فارسی و انگلیسی** — بسیار سبک و ۱۰۰٪ آفلاین.
- **سازگاری کامل با VPN**: هیچ تداخلی با سرویس VPN گوشی (`VpnService`) ندارد؛ یعنی می‌توانید همزمان هر VPN دلخواهی (V2Ray، WireGuard و...) را روشن کنید و تمام برنامه‌ها همچنان موقعیت GPS را از NotreMock بخوانند.
- **توقف خودکار برای برنامه‌های مستثنی (بدون روت)**: با استفاده از دسترسی استاندارد `Usage Access` (فقط هنگام روشن بودن سرویس و بدون نیاز به سرویس Accessibility) هنگام باز کردن برنامه‌هایی مثل **نشان، بلد، Google Maps، ویز، اسنپ و تپسی** موقعیت جعلی را موقتاً متوقف می‌کند و با خروج از آن‌ها دوباره فعال می‌شود.
- **کلید اضطراری (Kill Switch) و نگهبان نشت**:
  - دکمه فوری **Kill Switch** در برنامه، نوار اعلان و **Quick Settings Tile** بالای گوشی (توقف کامل یا پرش فوری به شهر امن جایگزین).
  - **Watchdog**: اگر سیستم‌عامل دسترسی Mock را قطع کند، فوراً هشدار می‌دهد.
- **اجرا با روشن شدن تلفن (`BOOT_COMPLETED`)**: راه‌اندازی خودکار پس از ریستارت گوشی.
- **رادار نشت و امتیاز حریم خصوصی**: بررسی وضعیت Mock App، هماهنگی TimeZone، اسکن پس‌زمینه Wi-Fi و بلوتوث، وضعیت سیم‌کارت و بررسی اختیاری تطابق کشور IP (VPN) با شهر (به‌صورت پیش‌فرض خاموش برای حفظ حالت ۱۰۰٪ آفلاین).
- **شبیه‌سازی طبیعی GPS**: لرزش طبیعی (Jitter)، پراکندگی تصادفی در شعاع شهر، تنظیم نرخ به‌روزرسانی و ارتفاع.
- **پشتیبانی کامل از فارسی (RTL) و انگلیسی**.

## مقایسه قابلیت‌ها در گوشی غیرروت، Shizuku و روت (LSPosed)

سیستم‌عامل اندروید برای حفظ امنیت، محدودیت‌هایی برای اپ‌های عادی بدون روت اعمال می‌کند. اولویت طراحی NotreMock **گوشی‌های استاندارد بدون روت** است:

| قابلیت | اندروید استاندارد (بدون روت) | حالت **Shizuku** (بدون روت) | حالت **Root + LSPosed** |
| :--- | :---: | :---: | :---: |
| تزریق Mock GPS و Fused Location | ✅ کامل | ✅ کامل | ✅ کامل |
| کارکرد همزمان با VPN | ✅ کامل | ✅ کامل | ✅ کامل |
| شروع خودکار در Boot و تایل نوار اعلان | ✅ کامل | ✅ کامل | ✅ کامل |
| استثنای خودکار برنامه‌های پیش‌زمینه (نشان، بلد، Maps) | ✅ با Auto-Pause | ✅ با Auto-Pause | ✅ همزمان و واقعی |
| استثنای اپ‌های پس‌زمینه (مثل Find My Device) | ❌ محدودیت اندروید | ❌ محدودیت اندروید | ✅ همزمان و واقعی |
| تنظیم خودکار منطقه زمانی (TimeZone) | ⚠️ لینک سریع / دستی | ✅ کاملاً خودکار | ✅ خودکار / مجزا برای هر اپ |
| مخفی‌سازی / جعل اطلاعات سیم‌کارت (`MCC/MNC`, `Cell ID`) | ❌ غیرممکن بدون روت (حالت هواپیما + Wi-Fi) | ❌ محدودیت اندروید | ✅ جعل کامل برای هر اپ |
| مخفی کردن پرچم `isMock()` | ❌ محدودیت اندروید | ❌ محدودیت اندروید | ✅ مخفی‌سازی کامل |

## راهنمای سریع راه‌اندازی (بدون روت)

۱. آخرین نسخه APK را از بخش **Releases** در گیتهاب دانلود و نصب کنید.
۲. بخش **تنظیمات توسعه‌دهنده (Developer Options)** را فعال کنید: `تنظیمات ← درباره تلفن ← ۷ بار لمس شماره ساخت (Build Number)`.
۳. وارد **Developer Options** شوید و در بخش **Select mock location app (انتخاب برنامه مکان آزمایشی)** برنامه **NotreMock** را انتخاب کنید.
۴. در برنامه دسترسی **موقعیت مکانی** (الزامی برای سرویس پس‌زمینه اندروید ۱۴+) و **استثنای بهینه‌سازی باتری** را تأیید کنید.
۵. شهر مورد نظر را انتخاب کرده و دکمه **شروع** را بزنید.

### نکات طلایی برای حریم خصوصی حداکثری
- همیشه کشور سرور **VPN** را با کشور شهر انتخاب‌شده یکی کنید.
- در تنظیمات مکان گوشی، **Wi-Fi Scanning** و **Bluetooth Scanning** را خاموش کنید.
- منطقه زمانی خودکار (**Automatic TimeZone**) را خاموش کرده و ساعت را روی شهر مقصد بگذارید (یا از Shizuku استفاده کنید).
- در گوشی غیرروت، برای جلوگیری ۱۰۰٪ از نشت دکل مخابراتی و سیم‌کارت، گوشی را در **حالت هواپیما + Wi-Fi** قرار دهید.

## ساخت خودکار در GitHub Actions و انتشار نسخه

تمام فرآیندهای تست، بررسی کد (Lint) و ساخت APK نسخه Debug و Release به صورت خودکار توسط **GitHub Actions** انجام می‌شود:
- با هر `push` روی شاخه `main`، تست‌های واحد و بیلد Debug اجرا و فایل APK در بخش Artifacts آپلود می‌شود.
- با زدن تگ نسخه جدید، نسخه Release به صورت خودکار منتشر می‌شود:

```bash
git tag v1.0.0
git push origin v1.0.0
```
